## 🌟 Key Features
- **Premium D2C Light Aesthetic:** Warm ivory backgrounds, deep forest green accents, muted antique gold styling, and typography using Playfair Display, Cinzel, and Plus Jakarta Sans.
- **Full Mobile Responsiveness:** Custom animated sticky navbar with backdrop-blur, smooth slide-out mobile drawer, and persistent quick-action bottom bar.
- **Product Catalog & Category Showcase:** Covers Almonds, Cashews, Pistachios, Walnuts, Raisins, Dates, Whole & Ground Masalas, Daily Cooking Essentials, and Custom Festive Gifting Hampers.
- **Quick WhatsApp Enquiry Modal:** Instant prefilled WhatsApp enquiry generation for all individual products.
- **Local SEO & Schema.org Markup:** Embedded JSON-LD `GroceryStore` structured data and localized meta tags for Ujjain search visibility.
- **Interactive Store Locator:** Direct Google Maps embed with one-tap directions.

## 🚀 Getting Started Locally

This website is built with vanilla HTML5, CSS3, and JavaScript, requiring zero external dependencies or build tools.

### Option 1: Direct File Opening
Double-click `index.html` to open it in any web browser.

### Option 2: Node.js Preview Server
```bash
npm start
# or
node server.js
```
Then visit `http://localhost:8080` in your browser.
